# Project guide

This is a complete static landing page with no framework, package installation, backend, or build step.

- `index.html`: page content, SVG icons, and Telegram invitation URL.
- `styles.css`: supplied dark card design, responsive layout, animations, keyboard focus, and reduced-motion support.
- `script.js`: 10-second countdown and Telegram navigation. Reads the destination from the CTA anchor to avoid duplicate configuration. The countdown remains hidden when JavaScript is unavailable.
- `netlify.toml`: publishes the project root.

Preserve the supplied branding and visual design. Use semantic HTML and plain CSS/JavaScript. Keep decorative SVGs hidden from assistive technology and honor reduced-motion preferences. No persistent data is collected. The displayed statistics are supplied static copy, not measured analytics. No roadmap items remain for the supplied page.
